## 2. Understanding of Requirements

1. **User-Friendly Weekly Schedule Breakdowns**:
   - Utilize `opening_hours.js` to parse OSM `opening_hours` syntax into clean daily schedules for each day of the week (Monday through Sunday).
   - Display each day on its own line using locale-specific weekday names (e.g. "Monday", "Tuesday").
   - Explicitly highlight/bold the schedule line corresponding to the current client weekday.
   - Gracefully fallback to raw schedule display for missing, complex, or unparseable schedules.

2. **Online Reservations & Food Ordering**:
   - Ingest online reservation links (e.g. OpenTable, Resy, Tock, SevenRooms) and online food ordering links (e.g. Toast, DoorDash, ChowNow, Slice) from OpenStreetMap tags (`reservation:website`, `order:website`, `takeaway:website`, etc.) and Overture Maps website listings.
   - Preserve `reservation_url` and `order_url` through spatial deduplication and output GeoJSON properties.
   - Display distinct icons and links (`📅 Reservations`, `🛍️ Order Online`) across the venue detail sheet, map hover tooltips, and sidebar cards.

3. **Page Scrolling & Layout Containment Investigation**:
   - Investigate why the page was stretching/scrolling up uncontrollably.
   - Identified two interrelated root causes:
     - Unconstrained flex sizing in `.poi-list-container` and `.filters-collapsible.open` where flex items with `min-height: auto` expanded the container and `document.body` to thousands of pixels, triggering layout reflows and map canvas resizing loops.
     - `card.scrollIntoView(...)` inside `setSelectedPOI` which triggered browser-level scroll chaining, scrolling ancestor windows/iframes whenever a marker was clicked.
   - Enforce strict CSS layout containment (`position: fixed`, `contain: strict;`, `min-height: 0;`, `flex: 1 1 0%;`, `overscroll-behavior: contain;`) and container-isolated scrolling (`listContainer.scrollTo(...)`).

4. **Project Documentation & License**:
   - Create a comprehensive `README.md` file describing the project, architecture, build and test instructions, and a step-by-step guide on generating custom walking isochrone files via [OpenRouteService Maps GUI](https://maps.openrouteservice.org/).
   - Add a disclaimer that the project was generated by Junie, licensed under the MIT License, with an invitation for pull requests.
   - Provide an official `LICENSE` file (MIT).
   - Update `FEATURES.md`, `documentation/user_guide.md`, and `documentation/developer_guide.md`.
