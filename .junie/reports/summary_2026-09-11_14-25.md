### Problem Interpretation & Goals:
1. **Basemap**: Replace raster basemaps with OpenFreeMap Positron vector tiles (`https://tiles.openfreemap.org/styles/positron`), maintaining zero API keys, no rate limits, and high contrast for walkshed polygon visualization.
2. **POI Styling**: Render points using custom vector SVG icon badges colored by category rather than simple circles, and add on-map venue name labels with white halos beneath the markers.
3. **Map Clicks & Bidirectional Selection**: Ensure clicking on a map point or label reliably opens the POI detail sheet, highlights the venue in the listing on the left, and scrolls it into view. Reciprocally, clicking a listing card zooms, centers, and highlights the POI on the map.
4. **Distance Sorting**: Sort places in the listing by Haversine great-circle distance from the conference center so that closer items appear before further items, displaying metric distance badges (e.g. `🚶 5 min (210 m)`).
5. **Data Pipeline Enhancements**: Add `--overture-min-confidence` (default 0.6) and `--blocklist-gers` CLI arguments to `pipeline/preprocess.py` to filter low-confidence or noisy Overture places and exclude specific GERS identifiers.
6. **Debug Mode**: Provide a debug toggle in the UI and via browser console (`window.toggleDebug()`, `window.ConferenceWalkerDebug`) to inspect OpenStreetMap and Overture GERS entity IDs on cards and in the detail sheet.
7. **Filter Panel UX**: Expand the filter panel in full length by default on startup with no results showing to eliminate visual clutter, with a dedicated "View Results" collapse action button.
8. **Configurable Default Categories**: Provide a global configuration (`src/config.ts`) permitting organizers to customize which categories are active by default on startup.
